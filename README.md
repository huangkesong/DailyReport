# 日报助手 Chrome 插件

这是一个帮助你轻松记录和管理日报的 Chrome 浏览器插件。

## 功能特点

- 快速记录每日工作内容
- 分类记录（已完成工作、进行中工作、遇到的问题）
- 自动保存数据
- 数据导出功能
- 每日提醒功能

## 安装说明

1. 打开 Chrome 浏览器，进入扩展程序页面（chrome://extensions/）
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本插件所在文件夹

## 使用说明

1. 点击浏览器工具栏中的插件图标，打开日报记录界面
2. 在相应的文本框中输入工作内容
3. 点击「保存日报」按钮保存内容
4. 需要导出时，点击「导出日报」按钮

## 提醒功能

- 插件默认在每天下午 5 点提醒填写日报
- 可以通过点击提醒通知直接打开日报填写界面

## 数据存储

- 所有数据保存在本地，不会上传到云端
- 自动保留最近 30 天的日报记录

## 文件结构

```
├── manifest.json     # 插件配置文件
├── popup.html       # 弹出窗口界面
├── popup.js         # 弹出窗口逻辑
├── background.js    # 后台服务脚本
└── images/          # 图标文件
    └── icon.svg     # 矢量图标
```

## 注意事项

- 建议每天及时记录工作内容，避免遗漏
- 可以随时保存，内容会自动保存在本地
- 导出的日报文件会自动下载到浏览器的默认下载目录

## 隐私说明

本插件所有数据均存储在用户本地，不会收集或上传任何用户数据。
